## ✨ Fitur

| Fitur | Keterangan |
|-------|------------|
| 💬 Chat real-time | Balasan instan dari Gemini AI |
| 💾 Riwayat tersimpan | Chat tidak hilang walau browser ditutup (localStorage) |
| 🔊 Mode suara | Bot membacakan jawaban dalam bahasa Indonesia |
| 🗑️ Hapus riwayat | Bersihkan chat kapan saja |
| 📱 Responsif | Nyaman dibuka di HP maupun laptop |
| ⚡ Super ringan | Pure HTML/CSS/JS, tanpa framework & backend |
| 🎨 Animasi pesan | Tampilan chat ala aplikasi messenger |
